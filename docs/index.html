企業ロゴストック

① ロゴを取得する

企業名を入力してください(改行・「、」・「/」・空白区切りで複数可、最大20社)。 取得済みの企業はストックが使われ、APIを消費しません。
初回のみ: GitHubトークンの設定(1〜2分)
取得の実行にはあなたのGitHubアカウントの権限が必要です。トークンはこのブラウザ内にだけ保存され、外部には送られません(GitHubへの認証のみに使用)。
  1. トークン作成ページを開く
  2. Repository access → Only select repositories → company-logo-fetcher を選択
  3. Permissions → Repository permissions → Actions を Read and write に
  4. 「Generate token」を押し、表示されたトークンをコピーして下に貼り付け
※ リポジトリへの招待(コラボレーター)を受けていない場合は、先に管理者へ依頼してください。

② ストックから探す(0社)

一致する企業がありません。「① ロゴを取得する」から追加できます。
「コピー」を押して PowerPoint に Ctrl+V(透過のまま貼れます)。うまくいかない場合は画像を右クリック→「画像をコピー」。 まとめて欲しいときは 全ロゴ入り pptx をダウンロード(1スライドに全社)。
