企業ロゴストック

① ロゴを取得する

企業名もしくは企業リストを記入してください。
※最大20社まで出力が可能です
※自動的に個社検索を行うため、改行・「、」・「/」・空白など、区切りの形式は自由です
GitHubトークンの設定(初回のみ・所要時間 約2分)
ロゴ取得の実行には、あなたのGitHubアカウントの許可証(トークン)が必要です。 トークンはこのブラウザ内にだけ保存され、GitHubへの認証以外には使われません。
事前準備: このリポジトリへの招待(コラボレーター)を受けていること。未招待の場合は管理者に依頼してください。
  1. GitHubのトークン作成ページを開く(GitHubへのログインを求められたらログイン)
  2. Token name: 好きな名前(例: logo-stock)/ Expiration: 好きな期限(例: 90 days)
  3. 「Repository access」で Only select repositories を選び、company-logo-fetcher を選択
  4. 「Permissions」→ Repository permissions → Actions を Read and write に変更
  5. ページ下部の緑の「Generate token」ボタンを押す
  6. 表示された github_pat_... をコピーして下の欄に貼り付け、「保存」
