# 企業ロゴ取得ツール

企業名のリストから、各社のロゴ画像をネット上から自動取得し、**背景を透過**して**余白をトリミング**した PNG を作るツールです。GUI のサムネイルをクリックするだけでクリップボードにコピーされ、**PowerPoint に Ctrl+V で透過のまま貼り付け**られます。

## できること

- 企業名リスト(`companies.txt`)からのロゴ一括取得
- 背景の自動透過(remove.bg)と余白の自動トリミング
- GUI でのロゴ一覧表示・クリック1回でコピー(PowerPoint 貼り付け対応)
- 「やり直し」ボタンで別の検索候補から取り直し
- 全ロゴを1スライドに並べた `logos.pptx` の自動生成
- 結果レポート(`report.csv`)・失敗リスト(`failed.txt`)の出力

## 必要なもの

各利用者が自分のAPIキーを2つ用意します(**キーは配布物に含まれません**)。

| サービス | 用途 | 無料枠 | 取得先 |
|---|---|---|---|
| SerpAPI | ロゴ画像の検索 | 250検索/月(1社=1検索) | https://serpapi.com/manage-api-key |
| remove.bg | 背景の透過 | 50回/月(preview品質) | https://www.remove.bg/dashboard#api-key |

## セットアップ

### exe 版(配布zipを受け取った場合)

1. zip を任意のフォルダに展開する
2. `config.example.toml` をコピーして `config.toml` を作る
3. `config.toml` に自分のAPIキーを記入する
4. `LogoTool.exe` を起動 → 画面上部に企業名を入力して「ロゴを取得」

初回起動時に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。

### Python 版(リポジトリから使う場合)

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy config.example.toml config.toml   ← APIキーを記入
.venv\Scripts\python src\main.py       ← 一括取得(CLI)
ロゴツール起動.bat                      ← GUI起動
```

## 使い方

### GUI(通常はこちらだけで完結します)

```
LogoTool.exe               (Python版: ロゴツール起動.bat)
```

1. **① 企業名を入力** — 1行に1社(行ごとに薄い罫線で区切られます)。他の資料の企業リストをそのまま貼り付けると、改行・読点・カンマ・スラッシュ・空白・行頭の番号や中黒などを判別して**自動で1行1社に整理**されます
2. **「ロゴを取得」** — 処理前に件数とAPI消費の見込みが表示されます。取得済みの企業はキャッシュを使うためAPIを消費しません。ボタンの左に **SerpAPI の残り検索数(例: 246/250)と remove.bg の残り無料回数** が常時表示されます(起動時と取得後に自動更新。この表示自体は検索数・クレジットを消費しません)
3. **② ロゴ一覧** — **サムネイルをクリック** → クリップボードにコピー → PowerPoint で Ctrl+V。一覧は**スクロール**でき(マウスホイール可)、右上の検索欄に企業名の一部を入れると**絞り込み**できます(大文字小文字は区別しません。Esc または × でクリア)
4. **やり直し** — 変なロゴが取れたときに、次の検索候補から取り直します
5. ロゴが増減・変更されると `logos.pptx` も自動で作り直されます

入力した企業リストは `companies.txt` に自動保存され、次回起動時に復元されます。

### GitHub版(チームで使う場合の推奨)

このリポジトリを GitHub に置くと、誰のPCにも依存せずチーム全員で使えます。

**ロゴを使う(ストック閲覧)** — GitHub Pages のページを開く(管理者から共有されるURL)
1. 検索ボックスで企業名を絞り込み
2. 「コピー」ボタン → PowerPoint で Ctrl+V(透過のまま貼れます)
3. まとめて欲しいときは「全ロゴ入り pptx をダウンロード」

**ロゴを取得する(新規追加)** — ページ内で完結します
1. ページ上部「① ロゴを取得する」の入力欄に企業名を入力(改行・「、」・「/」区切りで複数可、最大20社)
2. 「ロゴを取得」ボタン → 1〜2分で完了し、一覧に自動反映
3. 変なロゴが取れたときはカードの「やり直し」(別候補から取り直し)

初回のみの準備(1〜2分):
- 取得の実行にはリポジトリへの write 権限(コラボレーター招待)が必要です
- ページの案内に従い、GitHub の Fine-grained トークン(対象リポジトリのみ・Actions: Read and write)を作成して保存します。トークンは各自のブラウザ内にのみ保存されます

その他:
- APIキー(SerpAPI / remove.bg)はリポジトリの Secrets に管理者が1セット設定するだけ。利用者のキー取得は不要です
- API残数はページ上部に表示されます(全員で共有の枠)
- リポジトリの Actions タブ →「ロゴ取得」→「Run workflow」から直接実行することもできます(トークン不要のフォールバック)

### ストックの社内共有(OneDrive/SharePoint — 補助)

取得済みロゴの共有は **`output/` フォルダを OneDrive の共有リンクで配る**のが最も確実です。

- 共有リンクは Microsoft のクラウド経由なので、**あなたのPCがオフでも相手はいつでも**ロゴの閲覧・検索・ダウンロードができます
- ツールでロゴを追加取得すると、OneDrive の同期で**共有フォルダに自動反映**されます(PCがオンラインのとき)
- 相手向けの説明は `output/00_ご利用方法.txt` に同梱済み
- 権限は「表示可能(閲覧のみ)」にしておくと、誤削除を防げます

### Web共有版(補助: 在席中だけ、取得依頼も受け付けたいとき)

```
Webサーバー起動.bat        (Python版: .venv\Scripts\python src\webapp\server.py)
```

自分のPCでサーバーを起動し、表示される **`http://<PC名>:8531/`** を社内の人に共有します。開いた人はブラウザだけで:

- **ストックの閲覧・検索** — これまで取得した全ロゴが新しい順に並び、企業名で絞り込めます
- **ロゴの利用** — 画像を右クリック→「画像をコピー」→ PowerPoint に Ctrl+V(透過のまま)。ダウンロードや、全ロゴ入り pptx の一括ダウンロードも可能
- **新規取得・やり直し** — 入力欄に企業名を貼るだけ。**API枠はサーバー所有者のものを全員で共有**します(画面上部に残数を常時表示)

注意:
- サーバーを起動しているPCの電源が入っている間だけ使えます
- APIキーはサーバーPCの `config.toml` から読むだけで、閲覧者には渡りません
- 初回起動時に Windows ファイアウォールの許可ダイアログが出たら「アクセスを許可する」を選んでください
- 社内PCでのサーバー稼働可否は所属組織のポリシーに従ってください

### CLI(上級者向け・バッチ処理用)

```
LogoToolCLI.exe            (Python版: .venv\Scripts\python src\main.py)
```

- `companies.txt`(1行1社)を読んで一括取得します
- `--force` でキャッシュを無視して再取得(API消費あり)
- `--gui` を付けると処理後にそのままGUIが開きます

### 出力ファイル(`output/` フォルダ)

| ファイル | 内容 |
|---|---|
| `<企業名>.png` | 透過・トリミング済みロゴ |
| `logos.pptx` | 全ロゴを1スライドに並べたもの。**1社ずつコピーせず、まとめてロゴを出力したいときに便利**(GUI の「全ロゴ入り pptx を開く」から開けます) |
| `report.csv` | 企業ごとの成否・取得元URL(Excelで開けます) |
| `failed.txt` | 失敗した企業のみ。`LogoToolCLI.exe -i output\failed.txt` で再実行可 |

## 注意事項

### APIキーの扱い

- `config.toml` は**絶対に人に渡さない・Gitに登録しない**でください(`.gitignore` 登録済み)
- キーの値をチャット・メール等に貼らないでください

### API消費の目安

1社あたり: SerpAPI 1検索 + remove.bg 最大1クレジット。ただし次の場合は remove.bg を消費しません。

- 取得した画像が元から透過だった場合(実測で半数程度はこれ)
- キャッシュに前回の結果がある場合

### ロゴの利用について(重要)

- 企業ロゴは商標であり、多くの場合著作物です。**本ツールは取得を自動化するだけで、利用の可否は利用者の責任**です。各社のロゴ使用ガイドラインに従ってください。
- 画像検索経由のため、**非公式・旧版のロゴが取れることがあります。使用前に必ず目視確認**し、`report.csv` の取得元URLで出所を確認してください。おかしい場合は GUI の「やり直し」で次候補に切り替えられます。

### トラブルシューティング

| 症状 | 対処 |
|---|---|
| SSL証明書エラー | 社内プロキシ環境向けの対策(truststore)を組込済み。それでも出る場合は情報システム部門にプロキシのCA証明書について確認 |
| PowerPoint貼り付けで背景が黒い | 本ツールのコピーなら発生しません(検証済み)。Win+V の履歴からではなく、コピー直後に Ctrl+V で貼ってください |
| 「SerpAPI の利用上限」エラー | 無料枠(250検索/月)を使い切っています。翌月まで待つかプラン変更 |
| 「remove.bg のクレジットが不足」 | 無料枠(50回/月)を使い切っています。処理は自動中断され、キャッシュ済み分は影響ありません |
